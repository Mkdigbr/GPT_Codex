# Nexxus Scout

Aplicação web SaaS premium para inteligência comercial de marketplaces.

## Como executar

Abra `index.html` em um navegador moderno.

## Entregas incluídas
- Tela de login premium com feedback.
- Dashboard executivo com KPIs, blocos analíticos e microinterações.
- Módulos: Busca, Resultados, Lojas, Funil Comercial, Oportunidades, Histórico, Exportações, Usuários e Configurações.
- Dados fictícios realistas para demonstração.
- Tema escuro/claro.
- Estrutura técnica desacoplada com conectores Mercado Livre/Shopee.
- Schema SQL com tabelas solicitadas.
